# Roleplay Diary 
Roleplay Diary is a Windows application that was designed by roleplayers and made for the roleplay community! As roleplayers, we often spend a lot of time preparing our characters before we bring them into the world that we play them at. We spend time thinking of their backstory, their traits, and flaws, and more! Roleplay Diary was designed to be a companion to your roleplay journey. Throughout the life of your character you can record all major events about the character then when the story is done you can look back and have fond memories of that character.

## Installation 
1. Install the .NET 8 Desktop Runtime (WIndows x64) if you don’t already have it. 
2. Clone or download the Roleplay Diary repo and open a terminal in that folder. 
3. Run dotnet restore, then dotnet build -c Release. 
4. Start the app with dotnet run -c Release ( or run the build exe under bin\Release\net8.0-windows\)
On first launch it creates %AppData%\RoleplayDiary\ (SQLite DB, media, exports). You’re ready to add characters and diary entries.
